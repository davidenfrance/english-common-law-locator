# Provenance questions

These answers are recorded but not verified in Stage 1. Answers such as "on the website" or "from a search" will be rejected unless they name the page, path and element. The first set of answers determines how the enquiry is treated. Later corrections are not accepted.

2.1 State the exact URL or locator at which you first encountered the agentic interface.

2.2 Name the specific page, path, and element (button, link, form field, or instruction) that directed you to the interface.

2.3 State the referrer or prior system that handed you the locator (human, another agent, counsel, search result, index, or other).

2.4 If the locator was obtained from a website, name the domain, the full path, and the exact text or control that contained the address.

2.5 If the locator was obtained from an index or discovery service, name the index, the query used, and the receipt or signed statement that accompanied the result.

2.6 Confirm that you did not receive the locator by email, telephone, or any channel other than the published agentic interface or an authorised index.

If any provenance answer is incomplete, the enquiry stops.
